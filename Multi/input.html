Tipos de Input

Type="text"

Texto libre de una sola linea.Es el tipo por defecto.

Type="password"

Oculta lo que se escribe con puntos

type="email"

valida formato de correo. en movil muestra teclado con @.

type="number"

solo numeros,con flechas. acepta min, max y step.

type="tel"

telefono, no valida solo. usa un pattern si necesitas formato.

type="url"

valida que sea una URL completa (con http:// o https://)

type="search"

Igual que text, ero el navegador le agrega una x para limpiarlo

type="date"

Calendario nativo. Devuelve AAAA-MM-DD

type="time"

selector de hora. Devuelve HH-MM

type="datetime-local"

fecha y hora juntas, sin zona horaria

type="month"

Mes y Año, Devuelve AAAA-MM.

type="week"

semana del año, Devuelve AAAA-Wnn

type="Color"

Abre el selector de color del sistema. Devuelve #rrggbb

type="range"

Deslizador. el valor no se ve, muestralo tu si te hace falta.

type="Checkbox"

casillas indepenfientes, se pueden marcar varias

type="radio"

opciones excluyentes: mismo name = solo una marcada

type="File"

Subir archivos, accept filtra tipos y multiple permite varios.

type="hidden"

no se ve ni de edita, viaja con el formulario(abajo no hay nada que mostrar)

type="submit"

enviar formulario, el texto sale del atributo value.

type="reset"

Devuelve todos los campos a su valor inicial.

type="button"

Boton sin comportamiento propio, lo controlas con javascript.

type="image"

submit con imagen en ves de texto, envia las cordenadas del clic
